## Short project description

AI Monitor P4 turns a GUITION ESP32-P4 touchscreen into a USB desk companion for AI usage. NOVA and ORBIT react to recorded local token activity from Codex, ZCode, Claude Code and Gemini CLI. Supported providers also show account quota windows. Choose your robot and one of four themes; the Windows package includes the host runtime, flasher and firmware.

Some providers need external numeric telemetry; not every provider has automatic quota support. Token updates may lag generation, and the monitor is not a billing ledger.

## Suggested project introduction

> I built an open-source AI desk companion for the GUITION JC4880P433 ESP32-P4 touchscreen. It connects to a PC over USB and shows supported AI quota windows and recorded token activity. You can choose NOVA or ORBIT and switch between four UI themes. Codex setup offers the official CLI installation/sign-in, and the Windows download includes the host and firmware tools. Native token adapters cover Codex, ZCode, Claude Code and Gemini CLI; other integrations can use a numeric bridge.
