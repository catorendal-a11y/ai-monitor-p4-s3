# CLAUDE artwork

Pixel-art rendition of the small critter shown in the Claude Code terminal banner, redrawn
from its quadrant block characters by `scripts/generate_claude_svg.cjs`. One banner pixel is
half a terminal cell, so it is drawn twice as tall as it is wide. The six poses (work, done,
low, critical, sleep, blink) add expressions for the companion states used by NOVA and ORBIT.
