# ORBIT artwork

Original project-owned SVG geometry created for AI Monitor P4. ORBIT is a hovering capsule robot with six expressions, generated by `scripts/generate_orbit_svg.cjs`. It is covered by the project's MIT license.

Firmware RGB565+A8 frames and settings thumbnails are generated by `scripts/generate_nova_assets.cjs`. The alpha plane lets either companion blend into every UI palette without a fixed rectangular background.
